# ☕️ Caffeine Cove

A modern, elegant, and fully responsive landing page for an artisanal coffee house, built with clean semantic HTML5 and modern CSS3.

🔗 Live Demo: [mehdiheba640-create.github.io/Caffeine-Cove](https://mehdiheba640-create.github.io/Caffeine-Cove/)

---

## ✨ Features

- Fixed Navigation Bar: Clean desktop navigation bar featuring brand identity and smooth in-page navigation links.
- Hero Showcase: Engaging welcome section highlighting specialty coffee philosophy, value proposition, and call-to-action button.
- About & Philosophy: Structured showcase focusing on cafe atmosphere, ethical sourcing, and environmental sustainability.
- Specialty Menu Section: Multi-column grid display showcasing popular coffee selections with product thumbnails, descriptions, and pricing tags.
- Client Testimonials: Customer feedback cards complete with reviewer avatars and styled quote blocks.
- Table Reservation & Contact Area: Interactive booking form paired with an embedded interactive Google Map.
- Rich Footer: Multi-column layout containing business contact details, social media links, quick navigation links, and copyright info.

---

## 🛠 Built With

- HTML5: Semantic site layout (<header>, <nav>, <main>, <section>, <footer>), forms, and iframe embedding.
- CSS3: Custom layout system using CSS Grid and Flexbox, CSS custom properties (variables), transitions, and Google Fonts (*Oswald* & *Open Sans*).
- Font Awesome (v7.0.1): Scalable vector icons for interface controls, links, and contact badges.
- GitHub Pages: Static site deployment and continuous hosting.
